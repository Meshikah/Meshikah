# DEC-006 · All rights reserved until the 0.5 demo

- **Date:** 2026-11-01
- **Approver:** Armando
- **Status:** Accepted. Defers Q-002 to roadmap 0.5.

**Decision.** The repository stays "all rights reserved". The license model (open core or proprietary) is decided at roadmap 0.5, after the demo to three outside engineers.

**Rationale.** A license is hard to take back once published. Feedback from real users is the evidence needed to choose between adoption (open core) and control (proprietary).

**Alternatives.** Open core now, e.g. kernel and CLI under Apache-2.0 (deferred); fully proprietary now (deferred).

**Consequences.** No public release before 0.5. The demo repository uses synthetic data and is shared privately.
