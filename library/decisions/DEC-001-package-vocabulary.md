# DEC-001 · Package v0.1 vocabulary is canonical

- **Date:** 2026-10-31
- **Approver:** Armando
- **Status:** Accepted

**Decision.** The vocabulary of package v0.1 (library, work card, record; Light, Standard, Heavy, Critical; Scope, Plan, Review, Accept, Release, Learn; Owner, Approver, Builder, Checker, Librarian) is canonical. The reference framework was rewritten to 2.0 in that vocabulary.

**Rationale.** Plain words sell and teach better than gate and tier codes; one vocabulary avoids two competing truths.

**Alternatives.** Keep 1.1 terms (rejected: heavy, client-shaped); keep both with a mapping (rejected: two truths).

**Consequences.** Older Docs Hub repositories run through profiles (reference OS §3.3). The terminology map is in reference Standard §15.
